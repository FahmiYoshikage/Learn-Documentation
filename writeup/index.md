# Writeup 📚

> Ringkasan singkat untuk bagian "writeup" dalam dokumentasi VitePress.

**Tujuan**

- Menyimpan artikel, catatan teknis, dan tulisan mendalam yang berkaitan dengan proyek atau topik pembelajaran.

**Isi yang biasa ada**

- Artikel konsep dan teori
- Panduan dan how-to singkat
- Catatan eksperimen atau studi kasus

**Cara berkontribusi**

1. Buat file Markdown baru di folder `writeup/` (mis. `my-topic.md`).
2. Tambahkan judul (H1) dan isi tulisan.
3. Commit dan push — kalau perlu, tambahkan tautan di sidebar atau `index.md` untuk navigasi.

**Contoh**

- `VolatileMemory.md` — contoh catatan teknis yang sudah ada.

---

Jika ingin, saya bisa menyesuaikan gaya (lebih formal, lebih singkat, atau menambahkan frontmatter/metadata). ✅
